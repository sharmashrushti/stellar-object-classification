# stellar-object-classification
This notebook implements a complete ML workflow with the 'STELLAR CLASSIFICATION - SDSS 17' dataset. This dataset contains of 100000 observations of space taken by the SDSS (Sloan Digital Sky Survey). Every observation is described by 17 feature columns and 1 class column which identifies it to be either a Star, Galaxy or Quasar. The models used are Decision Trees, Random Forests, K-Nearest Neighbours, Support Vector Machines, Gradient Boosting, AdaBoost & XG Boost. The dataset is an imbalanced dataset. For this reason SMOTE is used to eliminate the imbalance between classes. Seven classification models have been developed that can accurately predict the class of new entities based on their features.
